# Viet Family — Website

Die statische Website kann direkt über `index.html` geöffnet oder auf einem einfachen Webserver bereitgestellt werden. Die vollständige Speisekarte wurde aus `Speise A4-2_260927_161621.pdf` (24 Seiten) als Text übertragen und ist unter `speisekarte.html` verfügbar. Sie umfasst 289 Positionen einschließlich Varianten, Sushi, Poke Bowls und Bubble Tea. Die interaktive Speisekarte zeigt jeweils eine Menügruppe und bietet eine Suche über alle Einträge. Die Quelldaten stehen in `menu-data.tsv`; nach Änderungen erzeugt `python3 build-menu.py` die HTML-Seite neu.

## Vor einer öffentlichen Veröffentlichung ergänzen

- Verifizierte Anschrift und Wegbeschreibung
- Telefonnummer, E-Mail oder tatsächlicher Reservierungsweg, falls gewünscht
- Betreiberangaben für das Impressum und geprüfte Datenschutzhinweise

Anschrift und Telefonnummer sind auf dem Deckblatt des neuen Menü-PDFs enthalten; die Kontaktbereiche können damit separat ergänzt werden. Betreiberangaben und E-Mail liegen weiterhin nicht vor. `rechtliches.html` ist ausdrücklich als unvollständige Struktur markiert.

Öffnungszeiten, Angebot zum Mitnehmen, Preise und die Speisekarte stammen aus den bereitgestellten Kundendateien. Schriftarten und Fotos werden lokal geladen; es gibt keine Analyse- oder Marketing-Skripte.
