# Viet Family — Website

Die statische Website kann direkt über `index.html` geöffnet oder auf einem einfachen Webserver bereitgestellt werden. Die vollständige Speisekarte wurde aus den bereitgestellten Menüfotos als Text übertragen und ist unter `speisekarte.html` verfügbar. Die interaktive Speisekarte zeigt jeweils eine Menügruppe und bietet eine Suche über alle Einträge. Die Quelldaten stehen in `menu-data.tsv`; nach Änderungen erzeugt `python3 build-menu.py` die HTML-Seite neu.

## Vor einer öffentlichen Veröffentlichung ergänzen

- Verifizierte Anschrift und Wegbeschreibung
- Telefonnummer, E-Mail oder tatsächlicher Reservierungsweg, falls gewünscht
- Betreiberangaben für das Impressum und geprüfte Datenschutzhinweise

Diese Angaben waren in den bereitgestellten Unterlagen nicht enthalten und wurden deshalb nicht erfunden. `rechtliches.html` ist ausdrücklich als unvollständige Struktur markiert.

Öffnungszeiten, Angebot zum Mitnehmen, Preise und die Speisekarte stammen aus den bereitgestellten Kundendateien. Schriftarten und Fotos werden lokal geladen; es gibt keine Analyse- oder Marketing-Skripte.
